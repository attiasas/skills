important design from Tech lead

The CLI reaches into indexer internals

cli/index.ts:4

The CLI imports indexer private helpers. Shipping one side without the other now breaks.

Suggestion Call the public repairIndex function and drop the private import.

minor defect from Code reviewer

The same import is a local nit

cli/index.ts:4

The public function is already what the CLI calls on the repair path. The extra import is style.

Critical 1

critical security from Security

Index path is not confined to the data directory

cli/index.ts:40

--index is passed to fs.readFile with no root check. A caller can read files outside the data directory.

Suggestion Resolve the path and reject anything that does not stay under the data root.

Important 3

important defect from Code reviewer

Invalid dates return no results

search.ts:25-27

A date that is not ISO is treated as an empty search, so a bad argument looks like no matches.

Suggestion Validate the format and throw, with a YYYY-MM-DD example.

important spec gap from Code reviewer

The flags are not discoverable

cli/index.ts:1-31

There is no --help. The plan says the flags must be discoverable. --concurrency exists only if the caller already knows it.

Suggestion Print usage, including --concurrency and --index.

important test gap from Code reviewer

Nothing asserts a path outside the data directory

cli/index.test.ts

The new --index flag has no test that an escaped path is rejected, so the security fix can land without a check.

Suggestion Add a test that a path outside the data root throws.
